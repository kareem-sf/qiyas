# Security policy

## Supported versions

Qiyas is young: only the newest release gets security fixes. Installed copies update themselves
from GitHub releases (Help, About, Check for updates).

| Version | Supported |
|---|---|
| Newest release | Yes |
| Older releases | No, please update |

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub:
[Security, Report a vulnerability](https://github.com/kareem-sf/qiyas/security/advisories/new).
Say what is affected, how to reproduce it (a drawing or script that triggers it helps) and what
an attacker could do with it.

We answer within a week, keep you told of the fix, and credit you in the advisory unless you
would rather not be named.

Things we especially want to hear about: a drawing, PDF or BOQ file that makes Qiyas run code or
write outside the folders it should; the MCP server (`127.0.0.1`, bearer token) answering anyone
it should not; and anything that lets an update install without a valid signature.
