# Qiyas

Desktop measurement CAD for quantity surveyors, by QS Mind. Open DWG and DXF, measure and edit, and let AI build and check BOQs.

Private. Tauri 2, React, Rust.

```bash
pnpm install
scripts/check.sh                                              # all local checks
pnpm tauri dev --config crates/qiyas-desktop/tauri.conf.json  # run the app
```

The opencadcodec library is MPL-2.0; its licence text is in `LICENSES/`.
